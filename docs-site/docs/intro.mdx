# WorldMapStudio

WorldMapStudio is a procedural, non-destructive map editor built on Godot 4 with C#.

## Requirements

- [Godot 4.7](https://godotengine.org/download) with .NET/C# support (the `godot` binary on your `PATH`)
- [.NET SDK 8.0](https://dotnet.microsoft.com/download)

## Getting started

```sh
git clone <repo-url>
cd WorldMapStudio
dotnet build
godot --headless --import --quit-after 1000
godot .
```

Re-run the import step after every build, before running headless or exporting.
